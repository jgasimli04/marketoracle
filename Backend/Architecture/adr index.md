## What is an ADR
Architecture Decision Record: a short note that captures a meaningful engineering decision and why it was made.

## When to write an ADR
- Adding/removing a service
- Changing DB strategy or schema approach
- Auth model changes
- Queue/eventing approach changes
- Provider swaps (payments/auth/etc.)
- Any decision with >2 weeks cost to reverse

## ADR template
- Title
- Status: proposed | accepted | deprecated
- Context
- Decision
- Consequences
- Alternatives considered
- Links (services/apis/data/runbooks)
