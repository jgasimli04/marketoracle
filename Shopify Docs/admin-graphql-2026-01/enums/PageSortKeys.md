# Page​Sort​Keys

enum

The set of valid sort keys for the Page query.

## Valid values

* ID

  Sort by the `id` value.

* PUBLISHED\_​AT

  Sort by the `published_at` value.

* TITLE

  Sort by the `title` value.

* UPDATED\_​AT

  Sort by the `updated_at` value.
