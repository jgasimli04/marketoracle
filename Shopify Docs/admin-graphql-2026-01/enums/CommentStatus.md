# Comment​Status

enum

The status of a comment.

## Valid values

* PENDING

  The comment is pending approval.

* PUBLISHED

  The comment is published.

* REMOVED

  The comment has been removed.

* SPAM

  The comment is marked as spam.

* UNAPPROVED

  The comment is unapproved.
