# Shipping​Package​Type

enum

Type of a shipping package.

## Valid values

* BOX

  A shipping box.

* ENVELOPE

  An envelope.

* FLAT\_​RATE

  A flat rate packaging supplied by a carrier.

* SOFT\_​PACK

  A soft-pack, bubble-wrap or vinyl envelope.
