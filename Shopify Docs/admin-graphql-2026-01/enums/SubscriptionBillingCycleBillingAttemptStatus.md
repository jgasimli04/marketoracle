# Subscription​Billing​Cycle​Billing​Attempt​Status

## Valid values

  Billing cycle has any number of billing attempts.

* HAS\_​ATTEMPT

  Billing cycle has at least one billing attempt.

* NO\_​ATTEMPT

  Billing cycle has no billing attempts.
