# Length​Unit

enum

Units of measurement for length.

## Valid values

* CENTIMETERS

  100 centimeters equals 1 meter.

* FEET

  Imperial system unit of length.

* INCHES

  12 inches equals 1 foot.

* METERS

  Metric system unit of length.

* MILLIMETERS

  1000 millimeters equals 1 meter.

* YARDS

  1 yard equals 3 feet.
