# Price​Rule​Shareable​Url​Target​Type

enum

The type of page where a shareable price rule URL lands.

## Valid values

* COLLECTION

  The URL lands on a collection page.

* HOME

  The URL lands on a home page.

* PRODUCT

  The URL lands on a product page.
