# Menu​Sort​Keys

enum

The set of valid sort keys for the Menu query.

## Valid values

* ID

  Sort by the `id` value.

* TITLE

  Sort by the `title` value.

* UPDATED\_​AT

  Sort by the `updated_at` value.
