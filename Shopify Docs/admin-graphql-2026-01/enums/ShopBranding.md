# Shop​Branding

enum

Possible branding of a shop. Branding can be used to define the look of a shop including its styling and logo in the Shopify Admin.

## Valid values

* ROGERS

  Shop has Rogers branding.

* SHOPIFY

  Shop has Shopify branding.

* SHOPIFY\_​GOLD

  Shop has Shopify Gold branding.

* SHOPIFY\_​PLUS

  Shop has Shopify Plus branding.
