# Url​Redirect​Error​Code

enum

Possible error codes that can be returned by `UrlRedirectUserError`.

## Valid values

* CREATE\_​FAILED

  Redirect could not be created.

* DELETE\_​FAILED

  Redirect could not be deleted.

* DOES\_​NOT\_​EXIST

  Redirect does not exist.

* UPDATE\_​FAILED

  Redirect could not be updated.
