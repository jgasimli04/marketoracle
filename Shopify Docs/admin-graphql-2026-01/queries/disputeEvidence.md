# dispute​Evidence

query

Returns a `ShopifyPaymentsDisputeEvidence` resource by ID.

## Arguments

* id

  [ID!](https://shopify.dev/docs/api/admin-graphql/latest/scalars/ID)

  required

  The ID of the `ShopifyPaymentsDisputeEvidence` to return.
