## Acceptance Criteria (Given / When / Then)

- **Given** I am a first-time user  
  **When** I open the dashboard  
  **Then** I see an explanation of each module at least once (What / Why / Inputs / Output / Example).

- **Given** I click any item from [[Feature list]]  
  **When** the module opens  
  **Then** it contains an obvious “Explain / Why” section and an example interpretation.

- **Given** I completed onboarding  
  **When** I come back later  
  **Then** I can re-open explanations anytime without hunting (help icon / explain toggle).
