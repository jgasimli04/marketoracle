# Glossary

- **UCP**: Universal Commerce Protocol
- **ACP**: Agentic Commerce Protocol
- **MCP**: Model Context Protocol
- **A2A**: Agent-to-Agent protocol/communication
- **UPID**: Universal Product ID (as referenced in Shopify catalog clustering)
- **Provenance**: where data comes from + freshness + how it was derived
- **Evidence Card**: a structured “why we believe this” block
